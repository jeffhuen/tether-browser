## 2. Frozen Cross-Slice Contracts

- **C1. RPC shapes**: method names, parameter JSON, and result JSON stay as they are at the baseline, except where C2 to C5 say otherwise. `browser.reviewList` keeps returning `{notes, pageUrl, viewport}` (`protocol.ReviewListResult`).
- **C2. Close all**: `browser.close` uses the `closeAll` parameter. Go already sends it. The extension reads it.
- **C3. Wait default**: when `timeoutMs` is absent, `browser.wait` waits 25000 ms in both drivers. The native bridge per-call deadline stays 30 s.
- **C4. Scroll point**: `browser.scroll` dispatches the wheel event at (400, 300) in both drivers.
- **C5. Focus**: `browser.focus` focuses the element without clicking it, in both drivers.
- **C6. Overlay copies**: the extension slice owns both `overlay.js` copies and keeps them byte-identical. The Go slice adds the byte-equality test and edits neither copy.
- **C7. Report hardening**: the JS review report follows the rules in `packages/protocol/review.go` (`sanitizeMarkdownLine`, `sanitizeComment`, `safeHTMLFence`). Page text cannot close a code fence or create a top-level heading.
